# CSSCraft

A modern, interactive CSS generator and visual builder designed to make writing and experimenting with CSS faster and easier.

CSSCraft provides visual tools for generating CSS without manually writing every property from scratch. It is built with Vue 3 and Vite, with a focus on clean UI, live previews, and practical CSS experimentation.

## ✨ Features

- 🎨 Visual CSS generators
- 📐 CSS Grid Generator
- 🧩 Grid Template Areas
- 📦 Flexbox Generator
- 🌑 Box Shadow Generator
- ✨ Text Shadow Generator
- 🔲 Border Radius Generator
- 📏 Spacing Generator
- 🔤 Typography Generator
- 🎨 Colors & Backgrounds
- 🎬 CSS Animations
- 🔄 CSS Transform
- 🖼️ CSS Filter Effects
- 🎯 CSS Variables
- ✂️ Clip Path
- 🎭 Masking
- 📊 CSS Columns
- 📐 Box Sizing
- 📝 `@font-face`
- ⚡ Live visual previews
- 📋 Generated CSS ready to copy
- 📱 Responsive interface
- 🌙 Dark mode

## 🛠️ Tech Stack

- Vue 3
- Vite
- Tailwind CSS
- Vue Router
- JavaScript
- Lucide Icons
